stream editor（流编辑器）

`sed` 按行读入文本，对匹配到的行执行命令，默认把结果输出到 stdout。

## 基本语法

```bash
sed [选项] '地址 命令' 文件
```

## 常用选项

| 选项      | 含义                                             |
| ------- | ---------------------------------------------- |
| `-n`    | 不自动打印，只有 `p` 才输出                                |
| `-i`    | 直接改文件；GNU 可写 `-i.bak` 先备份，macOS 要写 `-i ''`       |
| `-E`    | 用扩展正则，`+ ? \| ()` 不用转义（老写法 `-r`）                |
| `-e`    | 接多个脚本片段                                        |
| `-f`    | 从文件读脚本                                         |

## 地址

| 写法              | 匹配                    |
| --------------- | --------------------- |
| `3`             | 第 3 行                 |
| `$`             | 最后一行                  |
| `/re/`          | 含正则 `re` 的行           |
| `1,5`           | 第 1 到 5 行             |
| `/start/,/end/` | 从匹配 start 的行到匹配 end 的行 |
| `2~3`           | 从第 2 行起每 3 行取一行（GNU）  |
| `0,/re/`        | 范围从第 1 行开始，第一次匹配也算（GNU） |
| `/re/!`         | 取反，如 `/re/!d`         |

## 常用命令

| 命令            | 作用                       |
| ------------- | ------------------------ |
| `s/a/b/`      | 替换每行的第一个 `a`             |
| `d`           | 删除整行                     |
| `p`           | 打印（常配 `-n`）              |
| `a text`      | 行后追加（GNU 一行写法；BSD 要 `a\` 后换行） |
| `i text`      | 行前插入                     |
| `c text`      | 用 text 替换整行              |
| `y/abc/xyz/`  | 逐字符替换，长度必须相同             |
| `=`           | 打印行号                     |
| `q`           | 处理到这行就退出                 |

## s 的标志

| 标志       | 含义            |
| -------- | ------------- |
| `g`      | 替换行内所有匹配      |
| `2`      | 只替换第 2 个匹配    |
| `2g`     | 从第 2 个起全部替换   |
| `p`      | 打印发生替换的行      |
| `I`      | 忽略大小写（GNU）    |
| `w file` | 把替换结果另存到 file |

分隔符不必是 `/`，路径里斜杠多时换成 `s|/usr/local|/opt|g` 省得转义。

## 反向引用

`\1` 引用第 1 个捕获组，`&` 代表整个匹配：

```bash
sed -E 's/([a-z]+)@([a-z]+)/\2 at \1/' mail.txt
```

## 例子

删掉配置文件里两个键并写回原文件：

```bash
sed -i '/^GTK_IM_MODULE=/d; /^QT_IM_MODULE=/d' ~/.config/environment.d/fcitx5.conf
```

- `-i`：结果写回原文件，不打印
- `/^GTK_IM_MODULE=/d`：删掉以该串开头的整行
- `;`：同一轮里再执行第二个命令

其他常见用法：

```bash
sed '/^$/d' f                      # 删空行
sed -E '/^\s*(#|$)/d' f            # 删注释行和空行
sed -n '10,20p' f                  # 只打印 10–20 行
sed 's/$/ END/' f                  # 每行末尾加 " END"
sed -i 's/\r$//' f                 # 去掉 Windows 的 CRLF
```
