| 片段           | 含义                                       |
| ------------ | ---------------------------------------- |
| `PS1=`       | 定义主提示符变量                                 |
| `\[` … `\]`  | **bash 专用**：告诉 readline“这里面是不可见字符，别算进宽度” |
| `\e`         | ESC 字符（0x1B），ANSI 转义序列的开头                |
| `[38;5;141m` | ANSI SGR：`38` 前景色，`5` 用 256 色模式，`141` 色号 |
| `[0m`        | 重置所有样式（颜色、加粗全清）                          |
| `\t`         | 当前时间 `HH:MM:SS`                          |
| `\u`         | 用户名                                      |
| `\h`         | 主机名（短）                                   |
| `\w`         | 当前目录，家目录显示成 `~`                          |
| `\$`         | 普通用户显示 `$`，root 显示 `#`                   |
| `\n`         | 换行（两行式提示符里用）                             |
