```
curl -x http://127.0.0.1:7897 https://api.ipify.org
```
```
curl -x http://127.0.0.1:7897 -I https://www.google.com --max-time 10
```
-I 是 --head 的缩写，作用是只请求响应头，不下载正文。

curl

| 选项                  | 作用                      |
| ------------------- | ----------------------- |
| `-I`                | 只发 HEAD，只显示响应头          |
| `-i`（小写）            | 发 GET，**显示头 + 正文**      |
| `-s`                | 静默，不显示进度条               |
| `-o /dev/null`      | 把正文丢掉                   |
| `-w "%{http_code}"` | 只打印状态码，方便脚本用            |
| `-v`                | 显示完整请求/响应过程，排查 TLS 问题时用 |
